# 小狐狸侦探 · 单词

单文件网页应用，无需编译、无需账号，数据只存在 iPad 本地。
是给孩子背英语单词用的，背单词赚"线索"，线索喂给一只侦探狐狸。

**奖励体系只走宠物**——和另一套「原因我是的积分小天地」(`E:\Cowork\Claude\kid-points`)
是**互相独立**的两个应用，不共用积分、不共享数据。别把两者接到一起。

## 日常用法：本机改，iPad 上开（跟积分小天地一样）

改词表、改界面都在电脑上做，iPad 只是打开来看。**改完在 iPad 上拉一下刷新就是新的**，
不用上传、不用等发布。

1. 双击目录里的 **`start-server.bat`**。窗口里会直接列出该在 iPad 上输入的网址，
   比如 `http://192.168.100.165:8010`（**每台电脑不一样，看窗口里打的那行**）。
   它还会先查 8010 有没有被占，占了就停下不动——见下面那条 ⚠️。
2. iPad 和电脑连**同一个 Wi-Fi**，Safari 打开那个网址。
3. 分享 → 添加到主屏幕。以后从主屏图标点开就是全屏。
4. 用的时候**这个黑窗口别关**，关了 iPad 就打不开了。不用了就 Ctrl+C 或直接关窗口。

> 如果 IP 变了（换了 Wi-Fi、路由器重新分配）打不开：重新跑一次 bat，按新网址
> **删掉主屏图标重新添加**。名字和图标是「添加那一刻」定格的，只能删了重加。

想手动起服务也行：`python -m http.server 8010`，然后 `ipconfig` 自己找 IPv4 地址。

> ⚠️ **端口用 8010，别用 8000。** 积分小天地占着 8000。Windows 上 Python 的
> `http.server` 允许两个程序绑同一个端口且不报错，结果 `localhost` 和局域网 IP 会
> 分别打到两个不同的 App——你会以为打开的是这个，其实是积分小天地。
> 起服务前先查一下：`netstat -ano | grep ":8010"`。`start-server.bat` 已经替你查了。

## 离线可用（sw.js）

`sw.js` 把 5 个文件缓存到本地，**联网打开过一次之后，断网也能开**（飞机关、地铁里都行）。

几个点：

- ⚠️ **本机模式（iPad 走局域网 IP）离线缓存是不生效的**，电脑关了就打不开——这是
  浏览器的规矩，不是坏了：service worker 只在 https 或 localhost 才让注册，
  `http://192.168.x.x` 不算安全上下文，注册被浏览器直接拒掉。
  **想真正离线，只能走下面 GitHub Pages 的 https 地址。**
- **装一次就够，之后自动更新。** 缓存策略是「先给旧的、同时后台取新的」，
  所以**改完 index.html 不用升版本号**：第一次打开还是旧版，再打开一次就是新版。
  代价是「改完立刻打开」可能看不到新内容，别以为是没生效。
- 确认有没有生效：Safari 里把页面加到主屏 → **开飞行模式 → 从主屏点开**。
  能进就是成功了。同理，想彻底清缓存只能删掉主屏图标重新添加。

## 改词表

词表源文件放 `原始数据/words-yl*.json`，**文件名里的数字就是年级**：

```
words-yl3.json   3 年级
words-yl4.json   4 年级
words-yl5a.json  5 年级（5A）
```

改完跑一次：

```
python _build_words.py
```

它会把所有 `words-yl*.json` 合并灌进 `index.html` 的 `WORDS` 常量。
同一个词出现在多个年级时按**最早的年级**算（三年级的词不会被当成五年级新词再教一遍）。
**不要手改 index.html 里的 WORDS**，会被下次生成覆盖。

句子关的例句放 `原始数据/sentences.txt`（一行一句 `word | 英文 | 中文`），改完跑：

```
python _sent_work.py inject
```

它先拿句子跟词表对账（词必现 / 不超纲 / 空缺唯一），过了才把**挖空后的句子**灌进
`index.html` 的 `SENTS` 常量（小写词 → `I eat ___ for lunch.` 这样的挖空句）。
**不要手改 index.html 里的 SENTS**，会被下次生成覆盖。

## 三个方向

首页「开始查案」进去先选**今天练哪边**：**英译中**（看英文选中文）、**中译英**（看中文选英文）
或**句子关**（看英文句子填空）。三个方向各自独立、各刷各的。

- **英译中**常开，可以反复刷。**中译英要先用英译中热身**——今天还没刷英译中时它是灰的，
  上面挂把 🔒。
- **中译英的题从哪来**：排队。英译中**答对**的词进队首；今天没轮到的留在队里，**跨天不清**，
  明天接着考（不清空是因为清了她就漏词了）。考到就出队，答对答错都出。
  所以"当天答对的最优先、有余力再补昨天的存货"不用额外写逻辑——出题本来就从队首往下取。
- 中译英**只铺一批，刷完就结算**（不像英译中那样刷完自动续），不然又能攒出无限多的词。
- **中译英不自动发音**，音标也不给——那等于把答案递到她手上。答完才念，答完「再听一遍」才解禁。
- 中译英的选项优先挑**同首字母、同年级**的词当干扰项（形近才考得出拼写）。
  同中文释义的那 17 组永远不出现在同一题里（两个选项都"对"没法选）；
  多义释义只取第一个义项（「苹果；苹果树」→「苹果」）。

- **句子关**（常开，不设锁）：题干给一句英文、把当天背的那个词**挖空**，四选一填正确的英文，**全程没有中文提示**。
  - 选项跟中译英一样优先挑**同首字母、同年级**的形近词；音标不给、不自动发音（出声就是泄答案），答完才念。
  - **答对念的是整句**（把 ___ 填回那个词，让她听见这词在句子里长什么样），答错只念那个词
    （那会儿屏幕上正显示「填回整句」那行字，再念一遍整句会跟它抢注意力）。
    「再听一遍」跟着走——刚才念的是整句，这里也重念整句，不然对不上。
  - 答错不吐中文释义，而是**把词填回整句**给她看（比「word = 中文」更贴合句子填空）。
  - 词从哪来：跟英译中同一批池子（到期复习 + 5 年级新词 + 热身 + 送分题），只多一道「有句子」过滤。
  - **奖励照常**（线索 +1、复习排期、悬案簿都算），但**不掺和蛋**——蛋只认「英译中 + 中译英都做过」。
  - `show ... around` 这种带「...」的通配词没进句子关（挖空会连宾语一起吃掉，出不了选项）。

## 出题规则（英译中）

- **只限时间，不限题量**。5 分钟到了才结算；一批题刷完了会自动续一批，直到时间用完。
  词库全刷过一遍才会提前结束（655 词，正常刷不到）。
- **3-4 年级**：每批随机抽 30 个当热身。刷过一遍之后就进复习排期。
- **5 年级新词**：受「每天 N 个」限制（设置里可调，5-10，默认 8）。
  这是**按天**算的——刷完一轮再开一轮，当天额度用完就不再出新词，但复习照旧。
- 复习到期的词不分年级，答错过的排前面。

## 玩法 / 当前实现

- **极速刷**：限时 5 分钟，四选一，不限题数。答对自动发音、自动下一题；
  答错显示正确答案并停住等你点「继续」。
- **连对鼓励**：连对 3 / 5 / 8 / 12 / 20 个时，题目上方弹一个金色胶囊庆祝一句
  （「连破 3 案！」「8 连对，线索收割机！」…），之后每 10 个再来一次。
  级别越高，音效的音越高、串越长。答对时也会轻轻"叮"一声。
  设置里可以关掉音效（**不要做成"答对但其实是蒙的"那种自我否定的按钮**，试过，效果不好）。
- **只有时间到才结算**。题目刷完会自动续下去，词库全刷过一遍才会提前结束。
- **线索**：答对一个词 = 一条线索，今天的线索数决定狐狸的精神状态。
- **复习排期**：每个词有 0–5 级掌握度，答对升级、间隔拉长（10分钟→1天→3天→7天→14天→30天）。
  **答错不降级**，只是把复习提前到明天，避免打击。
- **狐狸**：带路的搭档，5 个形态，每进化一次多一件侦探装备（猎鹿帽→放大镜→风衣→金纹）。
  形态由**全部系列加起来**的解锁数决定，只增不减。点它会蹦一下并出声。
- **动物图鉴**：按**系列**分组（鸟类 / 海洋 / 昆虫 / 爬行 / 哺乳动物，每系列 12 只），
  每个系列在图鉴里有自己的页签和 0/12 进度。点页签就切到那个系列接着查。
  还没解锁的卡片只压暗一点、**不去色**——每颗蛋的颜色就是各自动物的颜色，看着有盼头。
- **悬案簿**（首页「🗂 悬案簿」）：答错的词自动立案，**累计**答对 3 次算破案，破案才移出。
  **答错进度不清零**，案子一直留着慢慢磨（已破的案子再答错才重新开案）。
  平时不刻意提醒——悬案按原有排期混在正常轮里出题，
  只在答对时把平时的「线索 +1」换成「🎉 破案！」。
  点词条可以**再听一遍发音**，但不进练习、不动任何进度。
  **答题过程中完全不提悬案**（只有「线索 +1」），结算页也只在"这轮真添了新案子/新存疑"时
  才多出一行「🗂 悬案簿又添了 N 件 · 去看看 →」，空手就不吭声。
- **每条的入册时间**：假线索/存疑每行右下角写着**它是几时进的悬案簿**——
  「刚刚 / 今天 / 昨天 / 3 天前 / 9-18 入册」。记的是**刚进这一类的时刻**（刚立案、刚变存疑），
  之后她再答对几次都不会把这个时间冲掉，不然看标签就认不出哪条是新的。
  **今天新入册的会顶到该段最前面**（否则刚立案的 `solved=0` 会被「快破案的排前面」
  压到最底，她点进来根本找不着）；其余仍按原来的顺序排。
- **存疑**（悬案簿里另立一类）：从没答错、但上次答对得反常地慢的词，用灰色单独列。
  「慢」是跟她**自己的平均速度**比（`耗时 > max(她的平均 × 1.6, 2.5 秒)`）；
  头 5 题还没攒出基线时用绝对阈值兜底（超过 6 秒算慢）；**超过 90 秒**才当成"人走开了"丢掉，
  15–90 秒照算慢，但**不进基线**（那是真不会，不是她变慢了，混进平均会把基线抬高）。
  慢答对只是这一级不算数、按当前级别重排，App 不显示级别，她收到的反馈仍然是"线索 +1"。
- **集中练**：想单独刷哪一类，点「假线索 / 存疑」那两行右边的**「集中练 →」**。
  **限时**（跟设置里的每轮时长走），只出这一类，练完回悬案簿。
  练习里**破案进度封顶在「有眉目」**——练到 2 就停，破案留给正常轮和挑战。
  这样练习是给挑战门槛添柴，不会把「同时 10 件有眉目」这个状态练没了
  （那是这两个入口唯一会打架的地方：不封顶的话，她练一遍就把有眉目的全破掉，
  挑战入口永远攒不出来）。存疑那条路更直接：**答快了就出列表**。
  中途按 ✕ 退出跟练完一样不推进动物，退回悬案簿。
  （挑战也一并不推了——之前 ✕ 退出会偷偷让小家伙长一步，跟「挑战不推进动物」对不上。）
- **挑战**：攒够 **10 件**「有眉目」（已累计答对 2 次）就出现挑战入口：
  **不计时**，只测这批，测完回悬案簿。每破一案 **+2 线索**（平时 +1），
  不走结算页、不推进动物、不算连续天数。
- **动物**：手里那只长一步——发现 → 幼年 → 成年，**3 步解锁一只**。
  前两步只给线索、**不公布名字**（"？？？"），她要自己猜；到成年那一步才点破名字和它的绝招。
  一只长大就换同系列下一只；这个系列集齐了会自动转到下一个系列。
  点首页「📖 动物图鉴」看图鉴。中途按 ✕ 退出也算一轮（答过题就行），照样长。
  **一步的条件是"今天英译中 + 中译英都做过"，而且一天只长一步**——不是每刷一轮长一步。
  当天英译中一个都没答对时中译英的池子是空的，这算中译英也完成了，蛋照长
  （不然她认真刷了一轮反而拿不到蛋）。结算页会写清楚今天还差哪个方向。

## 加动物

动物数据在 `_build_animals.py` 的 `ZOO_ANIMALS` 里（**不在 JSON**——每只动物都带一段 SVG，
塞 JSON 会变成一堆转义成一行的字符串，没法改）。加一只 = 加一个条目再跑：

```
python _build_animals.py
```

**两条硬规矩，脚本会拦：**

1. **前两条线索里不许出现动物名字**，名字只能出现在第三条。
   前两条要写成让她能猜、但猜不死心的那种线索。
2. **`series` 必须是 `SERIES` 里有的**。新开一个系列 = 在 `SERIES` 里加一条。

`facts` 必须是 3 条，对应第一步 / 幼年 / 成年。

第一步画什么**默认按 `tint`/`dark` 自动配一颗蛋**，不用写。
哺乳动物这类胎生的不下蛋，别用默认的蛋：
- 加 `"paw": True`，第一步自动改画一串**脚印**（颜色也按 `tint`/`dark` 走）；
- 在该系列上写 `entry` / `hatch`，换掉"侦查到一颗蛋 / 蛋里孵出了小家伙"这两句台词；
- 单只动物想写得更贴自己，用 `entry_label` / `hatch_label` 覆盖；
- 形象也换（水柱、背鳍…）就加 `entry_svg`；这一步只给文字线索、不放图形就写 `entry_blank: True`。

鲸 / 海豚 / 蝙蝠就是最后一种：它们不走路，脚印对不上，各自写了 `entry_svg` + `entry_label`。

例：

```python
{"id": "mammal", "cn": "哺乳动物", "entry": "发现一串脚印", "hatch": "窝里探出个小脑袋"},
{"id": "elephant", "cn": "大象", "series": "mammal", "paw": True, ...},
```
